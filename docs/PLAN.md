# แผนงาน · ระยะเวลา · ค่าใช้จ่าย

## ความเป็นไปได้
ทำได้ จุดเสี่ยงหลักไม่ใช่โค้ด แต่คือ (1) หน้า Meta เปลี่ยน DOM บ่อย ต้องอัปเดต selector (2) การอัปโหลดรูปและการดึงไฟล์วิดีโอขึ้นกับโครงสร้างจริงของหน้า (3) โควตา/ข้อจำกัดของบัญชี และความเสี่ยงด้านเงื่อนไขการใช้งาน (4) คุณภาพเสียงไทยและความต่อเนื่องของตัวละครจาก Meta

## เฟส

| เฟส | ขอบเขต | เวลา (คนเดียว พาร์ตไทม์) | สถานะ |
|---|---|---|---|
| 0 | โครงสร้างระบบ, Studio API, เก็บไฟล์ในเครื่อง | 2-3 วัน | ✅ ทำแล้ว |
| 1 | AI เขียนบท/แบ่งฉาก, UI Storyboard แก้ไขได้ | 3-5 วัน | ✅ ทำแล้ว (ปรับ prompt ต่อ) |
| 2 | Extension MV3: คิว, หยุด, overlay, โหมดเลือก/สแกน selector | 3-5 วัน | ✅ โครงพร้อม |
| 3 | **ผูกกับหน้า Meta จริง**: สแกน DOM, ตั้ง selector, ทดสอบแนบรูป/รอผล/ดาวน์โหลด, ตรวจข้อความโควตา | 3-7 วัน | ⏳ ต้องใช้หน้าจริงของผู้ใช้ |
| 4 | Render: normalize 9:16, transition, ซับไทย, loudnorm, caption | 2-4 วัน | ✅ ทำแล้ว (ทดสอบผ่าน) |
| 5 | TTS สำรองอัตโนมัติ (เชื่อม API), เทมเพลตตามประเภทคลิป, ตัวละครอ้างอิงรูป | 5-10 วัน | หลัง MVP |
| 6 | เก็บงาน: retry, log, หลายโปรเจกต์ขนาน, สำรองข้อมูล | 3-5 วัน | หลัง MVP |

**MVP (เฟส 0-4): ~2-4 สัปดาห์** ส่วนที่คาดเดาไม่ได้คือเฟส 3

## ค่าใช้จ่าย (ต่อเดือน)

| รายการ | ค่าใช้จ่าย |
|---|---|
| Meta AI / Vibes | ฟรีตามโควตาบัญชี |
| FFmpeg, Node, Chrome | ฟรี |
| AI เขียนบท (Claude API) | ประมาณ 1-5 บาท/คลิป ขึ้นกับรุ่นโมเดลและรูปแนบ → ~100-500 บาท/เดือนที่ 100 คลิป |
| TTS สำรอง (ใช้เฉพาะบางฉาก) | 0 (TTS ฟรี/ในเครื่อง) ถึงหลักร้อยบาท/เดือน (บริการเสียงไทยคุณภาพสูง) |
| จ้างพัฒนา (ถ้าจ้าง) | ราว 40,000-120,000 บาท สำหรับ MVP ขึ้นกับประสบการณ์ผู้พัฒนาและการดูแลต่อ |
| ดูแลรักษา | เมื่อ Meta เปลี่ยนหน้า: ตั้ง selector ใหม่ 10-30 นาที/ครั้ง ด้วยโหมดเลือก |
