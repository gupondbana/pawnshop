วิธีใช้ Clip Studio บน Windows (ไม่ต้องพิมพ์คำสั่ง)

ครั้งแรกครั้งเดียว
1. ดับเบิลคลิก "ติดตั้งครั้งแรก.bat"  (ถ้ามีหน้าต่างถามสิทธิ์ ให้กด Yes / ใช่)
2. รีสตาร์ทเครื่อง 1 ครั้ง
3. ติดตั้ง Extension ใน Chrome:
   - เปิด Chrome พิมพ์ chrome://extensions ในช่องที่อยู่เว็บ
   - เปิดสวิตช์ "Developer mode / โหมดนักพัฒนาซอฟต์แวร์" มุมขวาบน
   - กด "Load unpacked / โหลดส่วนขยายที่คลายการแพคแล้ว" แล้วเลือกโฟลเดอร์ extension
   - กดรูปจิ๊กซอว์มุมขวาบน แล้วกดหมุด Clip Studio Runner ให้ไอคอนโชว์ตลอด

ทุกครั้งที่ใช้งาน
- ดับเบิลคลิก "เปิดโปรแกรม.bat"  -> หน้า Studio จะเปิดใน Chrome เอง
- ห้ามปิดหน้าต่างสีดำ (ย่อไว้ได้)

(ไม่บังคับ) ให้ AI เขียนบทเก่งขึ้น
- สร้างไฟล์ชื่อ api-key.txt ไว้ข้างๆ ไฟล์นี้ แล้ววาง Claude API key ลงไปบรรทัดเดียว
- ถ้าไม่มี โปรแกรมจะใช้บทแม่แบบให้แก้เอง
