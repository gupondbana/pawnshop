## เริ่มใช้งาน

ต้องมี Node 20+ และ FFmpeg (`ffmpeg`, `ffprobe` อยู่ใน PATH) และควรติดตั้งฟอนต์ไทย เช่น *Noto Sans Thai*

```bash
cd studio
export ANTHROPIC_API_KEY=...   # ไม่ใส่ก็ได้ จะใช้บทแม่แบบออฟไลน์
npm start                      # http://127.0.0.1:4317
npm test                       # smoke test ทั้ง flow (จำลอง Extension)
```

ตัวแปรเสริม: `CLAUDE_MODEL`, `SUB_FONT` (ชื่อฟอนต์ซับ), `QUOTA_RETRY_HOURS` (ทำคิวต่ออัตโนมัติหลังโควตาหมดกี่ชั่วโมง), `CLIP_DATA_DIR`

ติดตั้ง Extension: `chrome://extensions` → เปิด Developer mode → Load unpacked → เลือกโฟลเดอร์ `extension/`

## ตั้งค่า Selector จากหน้าจริง (ต้องทำก่อนใช้ครั้งแรก)

โค้ดนี้ **ไม่มี selector ของหน้า Meta ฝังไว้เลย** (ดู `extension/selectors.js`) เพราะยังไม่ได้ตรวจหน้าจริง:

1. ล็อกอิน meta.ai เอง เปิดหน้าสร้างวิดีโอ
2. Popup → **สแกนโครงสร้างหน้า → Studio** — ได้ไฟล์ `studio/data/dom/snapshot-*.json` (รายการปุ่ม/ช่องพิมพ์/วิดีโอ, aria-label, placeholder) ใช้ตรวจโครงสร้างจริง ส่งไฟล์นี้มาให้ปรับโค้ดได้
3. Popup → กด **เลือก** ทีละ role แล้วคลิกองค์ประกอบจริง: `promptInput`, `submitButton`, `videoResult`, (`uploadInput`, `newChat`, `busyIndicator` ถ้ามี)
4. **ทดสอบ Selector** — ทุกตัวควรเจอ ×1 (ยกเว้น `videoResult` ที่อาจหลายอัน)
5. หน้าตั้งค่า: ใส่ `quotaTexts` = ข้อความจริงที่ Meta แสดงตอนโควตาหมด และ `promptSuffix` เช่นคำขอเสียงพูด/เพลง
6. ถ้าวิดีโอเป็น URL จาก CDN (ไม่ใช่ blob:) กด **อนุญาตดาวน์โหลดวิดีโอจาก CDN**

## การใช้งาน

สร้างโปรเจกต์ (หัวข้อ/รายละเอียด/ลิงก์/รูป) → **ให้ AI เขียนบท** → แก้บท ตัวละคร Prompt รายฉาก → **ส่งทุกฉากเข้าคิว** → Popup **เริ่มทำคิว** → เมื่อครบ กด **รวมเป็น MP4 9:16** → ได้ `output/final-*.mp4` + `caption.txt`

- **เสียงสำรอง**: ฉากไหนเสียง Meta ใช้ไม่ได้ ติ๊ก “ปิดเสียง Meta” และ/หรืออัปโหลดไฟล์ TTS — ระบบจะใช้เสียงนั้นแทนเฉพาะฉาก
- **หยุด**: ปุ่มหยุดใน popup, บน overlay ของหน้า Meta และ “หยุดคิว” ใน Studio — ฉากที่ทำค้างจะกลับเข้าคิว
- **โควตาหมด**: เจอข้อความใน `quotaTexts` → คิวหยุด ฉากกลับเป็น queued กด “ทำต่อ” ภายหลัง
- ไม่มีการหลบ CAPTCHA/ข้อจำกัด: เจอ CAPTCHA ระบบจะหมดเวลารอแล้วแจ้ง failed ให้ผู้ใช้จัดการเอง; เว้นช่วงระหว่างฉากค่าเริ่มต้น 20 วินาที

## ข้อควรระวัง

การควบคุมหน้าเว็บอัตโนมัติอาจขัดเงื่อนไขการใช้งานของ Meta และอาจทำให้บัญชีถูกจำกัด ใช้กับบัญชีตัวเองด้วยความเสี่ยงของตัวเอง หน้าเว็บ Meta เปลี่ยนบ่อย — เมื่อพังให้สแกนและเลือก selector ใหม่
